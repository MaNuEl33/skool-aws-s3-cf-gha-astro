# Popshop

Demo de tienda online creada con Astro. La web es estática; el catálogo, los filtros, el carrito y el formulario de newsletter funcionan en el navegador como demostración y no procesan pedidos ni guardan datos.

## Requisitos

- Node.js 26 o posterior
- npm

## Desarrollo

```sh
npm install
npm run dev
```

## Build estático

```sh
npm run build
npm run preview
```

El build genera el sitio estático en `dist/`, listo para publicarse en un hosting estático o servirse desde un bucket S3/CloudFront.
